# Skin Catalog — Android project

Демонстрационный каталог скинов в тёмном интерфейсе, рассчитанный на Android 10–11 (minSdk 29).
Это самостоятельное приложение: оно **не меняет файлы Standoff 2**, не выдаёт предметы в игре и не обходит защиту игры.

## Как собрать APK
1. Установите Android Studio (версия с поддержкой Android Gradle Plugin 8.6.1).
2. Откройте папку `Standoff2SkinCatalog` через **Open**.
3. Дождитесь синхронизации Gradle и установите Android SDK 35, если Android Studio попросит.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Google-вход
Кнопка пока показывает инструкцию. Для реального входа создайте проект Firebase, добавьте Android-приложение с package name `com.example.standoff2skincatalog`, настройте Google provider и интегрируйте Firebase Authentication. Не вводите пароль Google в сторонние формы и никому его не передавайте.

## Совместимость
- Минимальная версия: Android 10 (API 29)
- Целевая версия: Android 15 (API 35)
- Root не требуется

Названия предметов в каталоге — демонстрационные примеры; перед публикацией замените их на собственный разрешённый контент и изображения.

## Облачная сборка через GitHub Actions (с телефона)
1. Создайте на GitHub новый публичный или приватный репозиторий.
2. Загрузите в корень репозитория все файлы и папки проекта, включая скрытую папку `.github/workflows`.
3. Откройте вкладку Actions и запустите workflow `Build Android APK` (или дождитесь автоматического запуска после push).
4. После успешной сборки откройте завершённый запуск workflow, прокрутите до Artifacts и скачайте `standoff2-skin-catalog-debug-apk`.
5. Распакуйте архив артефакта и установите `app-debug.apk`.

Примечание: workflow собирает отладочный APK для тестовой установки. Это не релизная подпись для публикации в Google Play.
